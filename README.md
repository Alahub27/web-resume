## Descriptions:
This project is a web-based version of my current resume. The website resume was created by using HTML and CSS. This projects is hosted on Micosoft Azure. A printable PDF version of my resume is also included in my webpage via link.

## Instructions: 

Open the index.html file in a web browser by opening it in Visual Studio Code and clicking Open in Live Server

The resume.pdf file is a printable PDF version of current resume. It can be accessed through via link on the webpage.

The resume webpage is also hosted on Microsoft Azure and can be accessed through the projects HTTPS URL.
